# Mother of Pearl website copy

Faithful static front-end copy of https://motherofpearl.thedigitalyes.com/?embed=1, captured on 7 November 2026.

## Run locally

With Node.js installed, run `npm start` in this directory. Open http://127.0.0.1:4173/?embed=1 and click the seal to open the invitation. No package installation is needed.

## Files

- `dist/` is the complete deployable website, including original compiled React code, CSS, illustrations, fonts, videos, and music.
- `asset-manifest.json` records the copied original media.
- `scripts/verify.mjs` checks asset availability and deployment configuration.
- `.openai/hosting.json` identifies the private hosted copy.

The original names, dates, copy, colors, layout, animation, music, maps, hotel links, and credits are preserved. The countdown changes naturally with time. The original page title differs from the visible couple names; this is preserved as requested.

The source site's private database and admin credentials are not available in its public website. RSVP submission and admin login are intentionally disconnected from that service; they need your own backend before accepting real guest responses. No successful submission is simulated. Provider analytics scripts were omitted, and Google Fonts are served locally; these do not change the design.

This is the published front-end distribution, not the original editable React/TypeScript source project.
